# Flood rescue / 洪涝救援

See [the rescue guide](../../rescue/README.md) for participation policies, native
ns-3 setup, filter artifacts, outcome semantics and all twelve journal KPIs.

本模板用于有界救援决策研究：洪水和观测都是作者设定语义，不是水动力或感知模型。
默认 stub、无线关闭和按种子变化的机队可无密钥批量运行；无线关闭将如实过期。
开启无线需要真实 ns-3 RPC；过滤器需要真实导出的 `participation-filter.json`。

# Preserved research variants

- [AirFogSim crowdsensing and blockchain](airfogsim/README.md): the independent
  SUMO-based research simulator from `crowdsensing`, including its
  `blockchain_example` ancestor. Source, scenarios, algorithms, and experiment
  drivers are retained under their original internal layout.

These projects have their own dependencies and run directories. They are not
part of the current `src/aeroagentsim` API, distribution, or default test suite.

# Platform capability checklist

Q4 retirement reconciliation, 2026-10-08. **AeroAgentSim is the final platform; AeroBench
remains a read-only migration source until capability dispositions and the remaining
asset/authoring gates are resolved. This checklist does not authorize its deletion.**

Coverage: inherited migration/inventory rows, review F in
[PLATFORM-review.md](../reviews/PLATFORM-review.md), and the actual repository.
Two concurrent WorkBuddy DSH GLM sessions audited assets and capabilities;
Q4's executed verification is recorded in [RETIREMENT.md](RETIREMENT.md).
Historical measurements below remain historical; static path checks alone do
not promote a pending capability to ported.

**Statuses:** `ported` = retained/extracted capability with implementation and
verification evidence; `replaced-by` = a different implemented mechanism, with
scope/limits named; `intentionally dropped` = excluded from the new platform for
the stated reason (historical source is retained); `pending Pn` = unresolved work
assigned to the milestone in [PLAN.md](PLAN.md), including its follow-up gates.
`decision needed` = the owner must choose the stated cutover scope; no choice
has been inferred here. A partial replacement never implies every historical
behavior was migrated. For each row the final column states whether unresolved
work blocks deleting the AeroBench tree. Legacy-only gaps can stay in this repo
under the legacy extra; that is a scope option, not a completed kernel port.

Path prefixes below are repository-relative: **S** = `src/aeroagentsim`,
**F** = `frontend/src`, **T** = `tests`, **C** = `containers`. All named
implementation/test/artifact paths were checked for existence in Q4. A legacy
class still in its original module under S is not a port to kernel semantics.
P7b's region/draft/run/replay subset now has fresh REST/browser verification;
shared physical world compilation and complete Studio parity remain unresolved.

## Owner scope decisions

These choices remain open. Each affected row points to a decision below; its
third column names the actual remaining behavior. `Yes` means tree deletion
stays blocked until that work is delivered or the owner records a narrower
supported scope and preserves the excluded research assets. No option is
preselected. An optional feature need not block platform execution, but its
silent loss is not an acceptable retirement disposition.

| Decision | Required owner choice / remaining acceptance |
| --- | --- |
| D-deploy | Retain Kubernetes/distributed plans, remote gateway/auth or terminal sessions with corresponding implementations/tests; or accept local workers/Docker/HTTP model scope and archive the old deployments/drivers. |
| D-native | Finish native cancellation, contact authority and the named QoS/topology profiles; or explicitly accept current supported actions and best-effort radio limits. Native physical claims require measured backend gates. |
| D-studio | Finish the named terrain/facade/weather/vegetation/water/editor/physical-world pipeline; or accept verified bounded OSM ENU drafts and explicitly exclude those panels/physical publication. Shared Gazebo/SUMO/viewer frames/collisions need a real producer/test. |
| D-assets | Independently reproduce the textured Huangpu pack with its OSM/runtime/patch/config and per-texture licences, and preserve full legacy network source data; or accept the attributed ENU builder/current licensed display models and archive/exclude old presentation/sample assets. Unknown licences need rights evidence or release exclusion. |
| D-convert | Deliver importers for the named old suites/templates/public replay/verifier formats and generated contracts; or publish supported new-format-only scope, with a read-only historical archive and documented compatibility limits. |
| D-packs | Deliver the named benchmark scenario/package/metric/sensor/calibration/operations scope; or accept supported authored logistics/geometric inspection and archive/exclude that precise missing behavior. Genuine imagery/analysis needs a real sensor/model producer. |
| D-viewer | Deliver the named HUD/operations/dashboard/auth/terminal features and matched-scene/hardware-GPU acceptance; or accept the current inspected feed/replay UI and measured limits. Q4 browser success does not prove superiority or a frame budget. |
| D-legacy | For each named v1 gap choose a kernel port, continued independent `legacy` extra support, or explicit archive/exclusion. Retention in this repo can clear AeroBench tree deletion without a kernel-port claim; the owner must decide that compatibility policy before full cutover. |

## Historical defects and retirement limits (inventory §6)

The inventory's split state writers, wrong `source_id` subscription, unreachable
`status_changed` failure transitions, `workflow_created` subscription, fabricated
cron interval, missing airspace/frequency creation APIs, unwritten metrics,
missing examples and dead resource/db modules are not claimed fixed in v1.
New authority/schema/timer/record contracts replace those mechanisms where the
rows above name an implemented replacement; remaining legacy behavior stays
bounded to the optional runtime. The log-tail race is the one compatibility
runtime fix made in P8: readers share the append lock and still reject corrupt
completed records instead of skipping them.

Complete retirement still needs owner disposition of the decision-needed rows,
independent production or explicit replacement of the historical textured city
pack, preservation of research records and licences, and the acceptance gates
in [RETIREMENT.md](RETIREMENT.md). Public base-image dependencies and the two
old-tree asset/map defaults have been resolved. Q4 did not run Docker, calibrate
sensors, prove arbitrary ontology execution, or establish visual superiority.

Historical P8 verification: U is 328 non-Docker/non-model passes with five
deselections; legacy-extra verification recorded 48 passes and 19 missing-example
failures. Those numbers are retained as provenance, not Q4 results. The inherited
legacy tests/examples and current kernel platform are different scopes.

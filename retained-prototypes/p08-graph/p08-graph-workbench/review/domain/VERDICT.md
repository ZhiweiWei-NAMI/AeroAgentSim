**Static migration and the inspected semantic boundaries pass the independent regression suite: 38 passed, 0 failed.** The graph is suitable for scoped authoring/review. This is not an assurance of complete domain behavior, operational readiness, native predicate correctness, real permission, legal compliance, or physical execution.

## Boundaries that remain open

### Branch quality versus branch count

All 90 city steps share the same normal-branch sentence; A29/A30/A34 also share generic activity phase descriptions. Those records provide extraction and authored scenario structure. They do not prove that concrete failure/recovery behavior has been tested. The additional 140 designs address this review-design gap, not the missing executable validation.

### Physical routing

The mixer correction is verified. It does not prove every human/equipment route is resolved. In A09 step 5, a terminal is still the request target while the human operator and passive sampling tools are separately declared. The source explicitly leaves native routing unresolved. Preserve that gap; do not present the terminal as an observed physical sampler.

### Runtime and evidence

Native producers, evaluators, calibration, applicable grants, legal sources, command arbitration enforcement, actual material movement, time/clock alignment and independent effect evidence remain absent or partial where the source declares them missing. Neither a populated graph nor a passing static suite fills those gaps. A task can be physically feasible and still have unknown permission; an unrelated missing effect must not erase a known capacity deficit.

### Deduplication

Equal names or equal display values are never identity evidence. The current migration conservatively keeps 20,201 source node occurrences and 64,978 directed edge occurrences. No definition merge is performed on missing scope/revision, no parallel edge is removed, and unknown identity remains unknown. Exact lifecycle identity includes run, epoch, ID, generation and type; integer and string generation values are different.

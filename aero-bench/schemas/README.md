# Generated contracts

`tools/generate_contracts.py` is the only generator for this directory and
`frontend/src/generated/`. The source of truth is the strict Pydantic contract
graph.

```bash
python tools/generate_contracts.py --write
python tools/generate_contracts.py --check
```

The outputs include self-contained JSON Schema 2020-12 documents, the Control
API OpenAPI 3.1 document, TypeScript types generated by the pinned
`json-schema-to-typescript` package, and Ajv validators. `manifest.json` binds
every generated byte and records the generator/runtime-validator versions.

Do not hand-edit generated files. Public Trace replay remains offline: schema
`$id` values are URNs and no runtime validation fetches remote schemas.
